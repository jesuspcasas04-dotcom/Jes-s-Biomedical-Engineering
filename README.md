Version en Espanol

Bienvenido a mi portafolio de GitHub. Soy estudiante de Ingeniería Biomédica y este repositorio agrupa los proyectos, prácticas y desarrollos de software que he realizado durante mi formación académica y técnica. El enfoque principal de estos trabajos abarca la tecnología aplicada a la salud, el desarrollo de sistemas y la investigación clínica.

Estructura del Repositorio

El trabajo está organizado en diferentes directorios según la tecnología utilizada y su área de aplicación:

Trabajo de Fin de Grado (TFG): Investigación y desarrollo del proyecto final de grado, integrando los conocimientos adquiridos durante la carrera.

Sistemas y Aplicaciones Distribuidas: Proyectos de arquitecturas Cliente-Servidor y microservicios desarrollados en Node.js y Go, implementando comunicaciones RPC y REST.

Procesamiento de Senales y Datos: Algoritmos, análisis numérico y modelado matemático implementados mediante MATLAB.

Programacion Orientada a Objetos (POO): Proyectos estructurados enfocados en el diseño de software y la aplicación de los fundamentos de la POO utilizando Java.

Desarrollo Web y Scripts: Prácticas centradas en lógica de programación, asincronía y desarrollo de aplicaciones utilizando JavaScript.

Realidad Virtual Clinica: Desarrollo de entornos inmersivos para investigación clínica (proyecto ISLIA) utilizando el motor Unity y C#.

Redes y Comunicaciones: Simulaciones de topologías de red y configuración de protocolos de comunicación utilizando Cisco Packet Tracer.

Tecnologias y Herramientas

Lenguajes de programacion: Java, JavaScript, Node.js, Go, MATLAB, C#

Arquitecturas de software: Sistemas Distribuidos, REST, RPC, Cliente-Servidor

Distributed Systems and Applications: Client-Server architecture projects and microservices developed in Node.js and Go, implementing RPC and REST communications.

Signal and Data Processing: Algorithms, numerical analysis, and mathematical modeling implemented using MATLAB.

Web Development and Scripting: Practical assignments focused on programming logic, asynchronous execution, and application development using JavaScript.

Clinical Virtual Reality: Development of immersive environments for clinical research (ISLIA project) using the Unity engine and C#.

Networks and Communications: Network topology simulations and communication protocol configurations using Cisco Packet Tracer.
